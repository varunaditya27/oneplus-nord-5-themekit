# Security / ATELIER

ATELIER is a pre-alpha Android HOME application, not a privileged system modification.

**Do not** request root, install unreviewed Magisk modules, patch OxygenOS SystemUI, disable secure lock-screen protections, or request blanket Accessibility Service permissions to make the theme look more integrated.

The launcher catalog reads launchable activities solely for app presentation. The command interface has an explicit allowlist. The quick-settings Focus tile changes only an ATELIER preference. Artwork generation operates offline.

Never commit signing keys, API secrets, personal screenshots, proprietary fonts or private user data. Report security issues privately to the repository maintainer through GitHub where supported.
