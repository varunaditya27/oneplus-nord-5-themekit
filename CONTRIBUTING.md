# Contributing to ATELIER

ATELIER values restraint over novelty. Before adding a widget, animation or new accent color, explain the interaction it improves and show a 1x device screenshot.

## Contribution guidelines
1. Open an issue with the surface, problem, desired state and platform constraints.
2. Keep visual constants in shared token files and Android theme code.
3. Keep commands deterministic and allowlisted.
4. Add a test for changed parsing, state, data visibility and core visual behavior.
5. Respect reduced motion, device insets, system launcher restoration and Android permissions.
6. Do not add unlicensed fonts, third-party icon artwork or proprietary OEM assets.

Small, focused pull requests are preferred over theme overhauls. This is still pre-alpha and undocumented settings or APIs are not acceptable as default paths.
