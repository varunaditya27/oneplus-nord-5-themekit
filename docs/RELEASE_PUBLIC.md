# ATELIER 0.9.0 Preview 2

**The Black System.** A cinematic, original Android launcher and theme kit for the OnePlus Nord 5.

This is ATELIER's **first public GitHub prerelease**, packaged with the **actual APK** and the new original identity system.

### Highlights

- Original ATELIER monogram, path-drawn wordmark, adaptive Android launcher icon and skippable opening reveal.
- Full editable branding suite: SVG/PNG logo, wordmark, lockup, favicon, repo cover, social card, portrait splash, avatar and motif.
- Three procedurally rendered, touch-responsive wallpaper scenes: **Silkfield**, **Strata**, **Eclipse**.
- Three motion personalities: **Still**, **Signature** and **Expressive**, with reduced-motion support.
- 155 original semantic icons, per-app icon assignment, pinning and reset, four icon modes.
- Live battery, RAM and storage instruments, cinematic navigation and original vector clock.
- Export/import of your curated appearance using a local JSON backup.

### Downloads

**`ATELIER-v0.9.0-preview.2-debug.apk`**: directly installable Android test APK.

**`ATELIER-brand-kit-v0.9.0-preview.2.zip`**: all brand source SVGs, popular PNG export sizes, and design/legal guidance.

**`SHA256SUMS.txt`**: hashes for verifying downloaded files.

### Installing

Install the APK on an Android phone, open ATELIER, and optionally select it as the Home app. Keep the stock OnePlus launcher installed. To revert, select the stock launcher in Android **Settings → Apps → Default apps → Home app**. Back up custom settings through **EXPORT KIT** before uninstalling a debug build.

### Important caveats

- This is a **public prerelease**, not a production-stable or Play Store build.
- **Debug signing** is not stable between CI jobs. An APK from a later run may require uninstalling an older preview. Export your theme first.
- Android tests and emulator smoke checks are available; **physical Nord 5 / OxygenOS hardware compatibility and power use are not yet certified**.
- ATELIER cannot replace the secure OxygenOS lock screen, fingerprint animation, Always-On Display or stock notification shade.
