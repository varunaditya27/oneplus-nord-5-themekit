# Repository About profile

ATELIER's official GitHub **About** information is defined in [`.github/REPOSITORY_PROFILE.json`](../.github/REPOSITORY_PROFILE.json).

The public repository currently has no description, homepage or topics. The GitHub connector used to maintain the source cannot change repository metadata. These profile values must be applied once by a repository administrator using GitHub's About editor or an authenticated GitHub CLI.

## Copy-ready About fields

**Description**

> A dark-only Android launcher for OnePlus Nord 5, with cinematic interactions, procedural live wallpapers, and 155 original icons.

**Website**

https://varunaditya27.github.io/oneplus-nord-5-themekit/

**Topics**

`android  ·  android-launcher  ·  kotlin  ·  jetpack-compose  ·  oneplus  ·  oneplus-nord-5  ·  oxygenos  ·  dark-theme  ·  live-wallpaper  ·  icon-pack  ·  motion-design  ·  customization  ·  ui-design`

These are discoverability tags, not a declaration that the project is open-source. A project-wide license has not been selected.

## Apply via GitHub website

1. Open [the repository](https://github.com/varunaditya27/oneplus-nord-5-themekit).
2. In the **About** area at the upper-right of the Code page, click the gear/edit icon.
3. Paste the description and website above, then add the topics individually.
4. Save changes. The description and live website should become visible immediately.

Alternatively, from an authenticated local GitHub CLI session with administrator access, run:

```sh
bash scripts/repository/apply-about.sh
```

That script updates *only* description, homepage and topics. It does not change visibility, licensing, branch rules, Wiki or releases. Review the JSON first if you want to change the wording.

## What About is not

The repository description is limited in space, so keep it focused on what ATELIER actually provides. Do not claim production certification, full OxygenOS theming, fingerprint animation replacement or an open-source license that has not been selected.

For the project's rich presentation, use [README](../README.md); for downloads, link to the [public prerelease](https://github.com/varunaditya27/oneplus-nord-5-themekit/releases/tag/v0.9.0-preview.2).
