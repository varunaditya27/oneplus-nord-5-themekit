# ATELIER / Motion grammar

Motion is a response to intent, not decoration. Home and library surfaces crossfade in roughly 220ms; the original vector clock draws itself in a controlled one-shot reveal. Silkfield uses subtle Canvas strands and stops when invisible. It is **not yet GPU accelerated or device battery-profiled**.

Respect reduced motion in the launcher. Never flash, pulse, scroll randomly or create faux system telemetry. The main performance budget is idle battery consumption, not maximum frames per second.
