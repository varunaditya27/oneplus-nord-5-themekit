# Changelog

All notable ATELIER milestones are documented here. A green CI build verifies the source and APK, not physical Nord 5 compatibility.

## [0.9.0-preview.2](https://github.com/varunaditya27/oneplus-nord-5-themekit/releases/tag/v0.9.0-preview.2) · 2026-11-14

**First public GitHub prerelease.**

- Original open-A monogram, path-built wordmark, adaptive Android launcher icon and monochrome icon layer.
- Coordinated repository cover, brand lockups, favicon, social preview, splash and avatar.
- Skippable native opening title using the real logo.
- Public debug-signed APK, editable SVG/PNG brand kit and SHA-256 checksums.
- Android build/unit-test and emulator smoke verification completed. Nord 5 device certification remains open.

## 0.9.0-preview.1 · 2026-11-14

**Cinematic launcher preview.**

- Native Kotlin/Compose Home, searchable library, control/settings surfaces and command palette.
- Three original procedural wallpaper scenes: Silkfield, Strata and Eclipse.
- Still, Signature and Expressive animation presets, responsive gestures and native semantic icon transitions.
- 155 custom icons with optical treatments, app-specific assignment, favorite pinning and reset.
- Real battery, RAM and storage gauges.
- Local JSON theme backup/import with validation.
- Dark-surface regression fix and emulator screenshot/launch checks.

## 0.1.0 · Foundation

- Established ATELIER / The Black System and its dark-only material palette.
- Defined the Android launcher architecture, vector clock, command vocabulary and wallpaper lifecycle.
- Started the interactive web interface studies, native app and iconography system.
